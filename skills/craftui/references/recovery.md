# Сбои и продолжение работы

Скилл рассчитан на то, что агент может работать на слабой модели (например, через litellm), получать ошибки API, упираться в лимиты и терять контекст. Всё, что нужно для продолжения, лежит на диске.

## Где состояние

- `src/<kind>/<Name>/craftlog/state.json` — шаги, попытки, ошибки, ожидание пользователя.
- `craftlog/craftui.log.md` — история для человека.
- `AGENTS.md` и `CLAUDE.md` проекта направляют любого агента в новой сессии к `craftui status`.
- `.craftui/skill/` — копия SKILL.md и справочников: проект можно продолжить даже без установленного скилла.

## Что делать при сбое

| Ситуация | Действие |
|---|---|
| Ошибка вызова API или MCP (429, 5xx, таймаут) | подождать (10 с, 30 с, 60 с) и повторить тот же вызов; после 3 неудач — `craftui fail <Name> <step> "<ошибка>"` |
| Шаг упал 3 раза | `craftui next` подскажет, что делать: описать проблему пользователю и спросить; при согласии — `craftui step {"action":"skip",…}` |
| Контекст переполнен или сжат, новая сессия | `craftui status` → `craftui next` → продолжать с первого незавершённого шага |
| Не помнишь, что сделано внутри шага | шаги идемпотентны: повтори шаг целиком |
| Ответ команды слишком длинный | перенаправь в файл и смотри `tail -n 40` |
| Модель не видит изображения | работай по текстовой сводке verify (style-check, области diff) |

## Экономия контекста

- Сырые данные Figma — сразу в файлы: в chrome через receiver, в figma (Figma MCP) — по одному вызову с немедленной записью.
- Не открывай `raw/*` и `spec.json` (в проекте их чтение запрещено в `.claude/settings.json`). Данные для кода — `craftui digest {"action":"brief","entity":"<Name>"}`, точечно — `craftui digest {"action":"spec","entity":"<Name>","target":"<target>","layer":"<слой>"}`, сводка — normalize с "summary":true, правка свойства — `craftui spec {"action":"prop",…}`.
- Справочники читай по одному, по ссылке из `craftui next`.
- Если можно запускать отдельных агентов, отдавай им массовую работу (много вариантов, инлайн-передачу данных).

## Автопродолжение

**Stop-хук** (Claude Code, Codex): `craftui hooks {"action":"install"}` (только с согласия пользователя) пишет `.claude/settings.json` и `.codex/hooks.json`. Когда агент пытается завершить ход, хук проверяет состояние и, если есть шаги, которые можно сделать без пользователя, возвращает агенту «продолжи: craftui next». Хук не мешает, если:
- выставлено `awaitingUser` (`craftui step {"action":"wait",…}`) — поэтому перед вопросом пользователю `craftui step {"action":"wait",…}` обязателен;
- всё готово или шаги упали по 3 раза;
- 3 срабатывания подряд не принесли прогресса (защита от зацикливания).

**Autopilot** — для обрывов, после которых ход не возобновляется сам (агент упал на ошибке API):

```
craftui hooks {"action":"autopilot","agent":"claude"}   # или "agent":"codex"
```

Команда перезапускает агента в неинтерактивном режиме с промптом «продолжи craftui» и экспоненциальной паузой после ошибок (30 с → 10 мин). Она останавливается, когда всё готово, когда нужен ответ пользователя или после 3 запусков без прогресса. Команды запуска агентов настраиваются в `craftui.config.json` → `autopilot.commands` (`{prompt}` подставляется). В неинтерактивном режиме агенту нужны права на правку файлов и запуск `npm`/`node` — настрой их в агенте заранее.
