## craftui

This project is a component library imported from Figma with the `craftui` skill.
- Before any work here run `npm run craftui -- status`. If an import is unfinished, continue it with `npm run craftui -- next` (it prints the exact next step).
- Each entity keeps its Figma data, log, state and tests in `src/<kind>/<Name>/craftlog/`.
- Full workflow (works without the skill installed): `.craftui/skill/SKILL.md` and `.craftui/skill/references/`.
- Command reference: `npm run craftui -- help`.
